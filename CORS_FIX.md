# Исправление CORS ошибки

## Текущая проблема

Вы видите CORS ошибку, потому что:
1. Запросы идут напрямую к API серверу `https://db.acoustic.ru:3005`
2. API сервер не разрешает запросы с вашего домена GitHub Pages

## Решение

### Вариант 1: Настроить прокси-сервер (рекомендуется)

1. **Создайте прокси-сервер через Cloudflare Workers**:
   - Зарегистрируйтесь на https://workers.cloudflare.com/
   - Создайте новый Worker
   - Используйте код из `docs/cors-proxy-example.md`
   - Получите URL вашего Worker (например: `https://your-proxy.workers.dev`)

2. **Обновите секрет в GitHub**:
   - Перейдите в **Settings** → **Secrets and variables** → **Actions**
   - Найдите секрет `VITE_API_URL` (или создайте `VITE_API_PROXY_URL`)
   - **Измените значение** на URL вашего прокси + `/api/v1`
   - Пример: `https://your-proxy.workers.dev/api/v1`
   - **ВАЖНО**: Это должен быть URL прокси, а НЕ URL API!

3. **Пересоберите проект**:
   - Сделайте любой коммит и push в ветку `main`
   - Или запустите workflow вручную: **Actions** → выберите последний workflow → **Run workflow**

4. **Проверьте результат**:
   - Откройте сайт на GitHub Pages
   - Откройте консоль браузера (F12)
   - Вы должны увидеть: `API Configuration: { hasProxy: true, proxyUrl: "..." }`
   - Если видите `hasProxy: false`, значит секрет не был правильно использован

### Вариант 2: Попросить настроить CORS на API сервере

Если у вас есть доступ к серверу `https://db.acoustic.ru:3005`, попросите администратора добавить ваш домен GitHub Pages в список разрешенных источников.

## Проверка

После деплоя:
1. Откройте сайт на GitHub Pages
2. Откройте консоль браузера (F12)
3. Попробуйте выполнить расчет конструкции
4. В консоли должны быть логи:
   - `API Configuration:` - показывает, используется ли прокси
   - `[API] Using proxy: ...` - если прокси используется
   - `[API] No proxy configured...` - если прокси НЕ используется

Если все еще видите ошибку CORS, проверьте:
- Правильно ли указан URL прокси в секрете
- Был ли проект пересобран после изменения секрета
- Работает ли ваш прокси-сервер
