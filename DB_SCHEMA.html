API Endpoints Express REST

Авторизация

МетодПутьТело запросаОписание
POST /api/auth/register { full_name, email, phone, office_address, password } Регистрация нового пользователя
POST /api/auth/login { email, password } Вход → access JWT + refresh cookie
POST /api/auth/refresh *(httpOnly cookie)* Обновить access token
POST /api/auth/logout — Выход, очистка cookie

Пользователь требует auth

МетодПутьТело запросаОписание
GET /api/users/me — Данные текущего пользователя
PUT /api/users/me { full_name, phone, email, office_address } Обновить данные профиля

Коммерческие предложения требует auth

МетодПутьТело запросаОписание
POST /api/kp { form, calc_tables, montage_data, service_rows, total_cost } Создать и сохранить КП
GET /api/kp — Список КП текущего пользователя
GET /api/kp/:id — Полные данные одного КП (только своего)
GET /api/kp/:id/pdf — Сгенерировать и скачать PDF (Puppeteer)
