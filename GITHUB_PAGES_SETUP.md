# Настройка GitHub Pages

## Проблема: Ошибка 404 для main.jsx и других ресурсов

Эта ошибка возникает, когда базовый путь (base path) в конфигурации Vite не соответствует имени вашего репозитория на GitHub.

## Решение

### Шаг 1: Определите имя вашего репозитория на GitHub

Ваш репозиторий доступен по адресу:
- `https://github.com/ваш-username/имя-репозитория`

Имя репозитория - это последняя часть URL (например, если URL `https://github.com/user/Oldcalc`, то имя репозитория - `Oldcalc`)

### Шаг 2: Обновите vite.config.js

Откройте `vite.config.js` и измените значение `base`:

**Если репозиторий называется `Oldcalc`:**
```js
base: process.env.NODE_ENV === 'production' ? '/Oldcalc/' : '/',
```

**Если репозиторий называется `my-repo`:**
```js
base: process.env.NODE_ENV === 'production' ? '/my-repo/' : '/',
```

**Если репозиторий находится в корне GitHub Pages (username.github.io):**
```js
base: '/',
```

### Шаг 3: Пересоберите проект

```bash
npm run build
```

### Шаг 4: Убедитесь, что деплой настроен правильно

- Если используете GitHub Actions, убедитесь, что workflow деплоит из папки `dist`
- Если используете ручной деплой, загрузите содержимое папки `dist` в ветку `gh-pages` или в папку `docs` в ветке `main`

### Альтернативное решение: Использование переменной окружения

Вы можете установить переменную окружения перед сборкой:

```bash
VITE_BASE_PATH=/ваше-имя-репозитория/ npm run build
```

## Проверка

После деплоя откройте консоль браузера (F12) и проверьте:
- Нет ошибок 404
- Все ресурсы загружаются с правильными путями (должны начинаться с `/имя-репозитория/`)
