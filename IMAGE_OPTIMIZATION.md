## Настройка Cloudflare Worker

### Шаг 1: Создание Worker

1. Зайдите на [Cloudflare Dashboard](https://dash.cloudflare.com/)
2. Перейдите в **Workers & Pages**
3. Нажмите **Create application** → **Create Worker**
4. Дайте название вашему Worker (например, `acoustic-api-proxy`)

### Шаг 2: Установка кода

1. Откройте файл `cloudflare-worker-simple.js` из этого проекта
2. Скопируйте **весь код** из файла
3. Вставьте его в редактор Cloudflare Worker
4. Сохраните изменения

### Шаг 3: Настройка переменных окружения (опционально)

Если вы хотите использовать другой API URL:

1. В настройках Worker найдите **Variables and Secrets**
2. Добавьте переменную:
   - **Variable name:** `API_BASE_URL`
   - **Value:** `https://db.acoustic.ru:3005`

### Шаг 4: Настройка домена

1. В настройках Worker найдите **Triggers** → **Routes**
2. Добавьте кастомный домен или используйте домен `*.workers.dev`
3. Скопируйте URL вашего Worker (например, `https://acoustic-api-proxy.your-username.workers.dev`)

### Шаг 5: Настройка переменных окружения в проекте

Для **GitHub Pages** (production):

1. Зайдите в **Settings** вашего репозитория
2. Перейдите в **Secrets and variables** → **Actions**
3. Добавьте секрет:
   - **Name:** `VITE_API_PROXY_URL` (или `VITE_API_URL`)
   - **Value:** URL вашего Cloudflare Worker + `/api/v1`
   
   Например: `https://acoustic-api-proxy.your-username.workers.dev/api/v1`

Для **локальной разработки**:

Создайте файл `.env.local` (не коммитьте в git):

```env
VITE_API_PROXY_URL=https://acoustic-api-proxy.your-username.workers.dev/api/v1
```

## Оптимизации в коде

### Lazy Loading
Все изображения загружаются только когда они приближаются к области просмотра:

```jsx
<img 
  src={imageUrl} 
  loading="lazy"      // Отложенная загрузка
  decoding="async"    // Асинхронное декодирование
  onError={(e) => {   // Обработка ошибок
    e.target.style.display = 'none';
  }}
/>
```

### Предзагрузка критических изображений
Иконки секций предзагружаются при старте приложения:

```jsx
useEffect(() => {
  const sectionIcons = mainSections.map(section => getImageUrl(section.icon));
  preloadImages(sectionIcons, 4); // Загружаем по 4 параллельно
}, []);
```

## Проверка работы

1. Откройте DevTools (F12)
2. Перейдите на вкладку **Network**
3. Перезагрузите страницу
4. Проверьте:
   - Изображения загружаются только при скролле к ним
   - При повторной загрузке изображения берутся из кэша (статус 200 из cache)
   - Запросы идут через ваш Cloudflare Worker URL

## Устранение проблем

### Изображения не загружаются
1. Проверьте, что Cloudflare Worker развернут и работает
2. Проверьте URL в переменной окружения `VITE_API_PROXY_URL`
3. Проверьте консоль браузера на наличие ошибок

### Медленная загрузка даже с Worker
1. Убедитесь, что кэширование включено в Worker
2. Проверьте настройки кэша в Cloudflare Dashboard
3. Проверьте, что изображения действительно идут через Worker

### Worker все еще требует VPN
1. Убедитесь, что Worker использует правильный API URL
2. Проверьте, что домен `db.acoustic.ru` доступен из региона размещения Worker
3. Рассмотрите использование другого прокси-сервера

## Дополнительные улучшения

Если проблемы сохраняются, можно:

1. **Использовать CDN для изображений:** загрузить изображения в Cloudflare R2 или другой CDN
2. **Оптимизировать размер изображений:** использовать WebP формат или сжатие
3. **Использовать Service Worker:** для более агрессивного кэширования на клиенте
