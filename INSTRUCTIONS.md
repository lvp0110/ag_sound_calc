# Инструкция по использованию

## Быстрый старт

1. Перейдите в директорию проекта:
```bash
cd calc-react
```

2. Установите зависимости (если еще не установлены):
```bash
npm install
```

3. Запустите dev сервер:
```bash
npm run dev
```

4. Откройте браузер по адресу, который покажет Vite (обычно http://localhost:5173)

## Использование

- Откройте `/calc` для доступа к калькулятору
- Можно передать ID конструкции через URL: `/calc/AG.F601`
- Выберите категорию, подкатегорию и конкретную конструкцию
- Заполните параметры и нажмите "расчет конструкции"
- Используйте кнопки "экспорт в ERP" и "сохранить в Excel" для экспорта данных

## Основные изменения при конвертации из Vue

1. **Template → JSX**: Все Vue шаблоны конвертированы в JSX
2. **v-if → условный рендеринг**: `{condition && <Component />}`
3. **v-for → map()**: `{items.map(item => <Component key={item.id} />)}`
4. **v-model → value + onChange**: Контролируемые компоненты React
5. **computed → useMemo**: Для вычисляемых значений
6. **methods → функции**: Обычные функции или useCallback
7. **$router → useNavigate**: React Router для навигации
8. **lifecycle hooks → useEffect**: Для побочных эффектов
