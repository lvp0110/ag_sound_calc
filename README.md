# Calculator React App

Это React приложение, созданное на основе Vue компонента калькулятора конструкций.

## Установка

```bash
npm install
```

## Запуск

```bash
npm run dev
```

## Структура проекта

- `src/App.jsx` - Главный компонент с роутингом
- `src/components/Calculator.jsx` - Основной компонент калькулятора
- `src/components/Calculator.css` - Стили для калькулятора

## Основные функции

- Выбор категорий и подкатегорий конструкций
- Расчет материалов для различных типов конструкций
- Экспорт данных в Excel
- Копирование данных в буфер обмена для ERP систем

## API

Приложение использует API endpoint:
`https://db.acoustic.ru:3005/api/v1/calcIsolation/byProduct`

## Зависимости

- react
- react-router-dom
- exceljs
- file-saver
- sweetalert2

## Примечания

Компонент конвертирован из Vue в React. Некоторые шаблоны форм могут требовать дополнительной доработки в зависимости от конкретных требований.
